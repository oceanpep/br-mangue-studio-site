Scenario and inputs

The run used land-cover categories and matching DEM data on the same grid, with a 6.0 m tidal influence and 0.3 mm/year sea-level-rise setting. Soil and suitability were disabled; migration fallback was enabled.

What was checked

The final rasters and trajectory matched between engines for this recorded run. This supports computational consistency for the tested settings. It does not demonstrate ecological accuracy or predict speed on other hardware.

The workstation used an Intel Core i3-1215U and 19.7 GiB of RAM. Annual map writing, repeated measurements, and other hardware can change runtime and memory use. The archived block memory figure predates an input-grid release optimization.

These timings are not a controlled engine comparison.The runs used different class mappings, and one run did not record its maturity setting. The audit sampled the first and final annual maps against recorded trajectories; it did not compare every map cell by cell.

The two runs took about 8 h 03 min combined. Their records did not include executable version, code commit, operating-system edition, processor model, or input checksums. Treat these as descriptive measurements rather than fully reproducible performance claims.
