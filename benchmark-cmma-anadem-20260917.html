This archived run covers the full Costa de Manguezais de Macromaré da Amazônia (CMMA) raster: 18,352 × 21,350 cells at 30 m, using 2024 land-cover data and matching ANADEM terrain elevation. It measures one transition, from 2024 to 2025. Annual GeoTIFF export was disabled, so the times describe simulation work rather than a 76-year run with map writing.

Inputs and scenario

CMMA V2 land-cover data for 2024 and matching ANADEM 30 m terrain tiles. Tidal influence: 6.0 m. Sea-level rise: 0.3 mm/year. Soil and suitability layer disabled; migration fallback enabled.

What this check shows

The recorded final rasters and trajectory matched between the two engines for this test. This supports computational consistency for these settings; it is not ecological validation or a universal speed estimate.

The run used an Intel Core i3-1215U with 19.7 GiB of RAM. Annual map writing, repeated measurements, and other hardware can change elapsed time and memory use. The historical block memory figure is from the archived run before an input-grid release optimization.

These two Windows timings are not a controlled engine comparison.Although both metadata files name the same land-cover and elevation inputs, the class mappings differ. The maturity setting is also absent from the block-run metadata. The audit sampled the 2025 and 2100 maps and checked them against the recorded trajectories; it did not compare all 76 rasters pixel by pixel.

The recorded total across both runs is approximately 8 h 03 min. The run folders did not record the executable version, code commit, Windows edition, CPU model, or input-file checksums, so the results are descriptive evidence for those runs rather than a fully reproducible performance claim.
