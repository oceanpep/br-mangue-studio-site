Teste o modelo com dados reais

Baixe este projeto para testar o BR-MANGUE Studio com o exemplo da Ilha do Maranhão. O ZIP inclui o projeto e todos os arquivos de entrada necessários.

Baixar projeto de teste (ZIP de 4,9 MiB)
  1. Extraia o ZIP e mantenha os arquivos e pastas juntos.
  2. Abra o BR-MANGUE Studio e selecione Projeto → Abrir projeto.
  3. Escolha brmangue_project.json. Os dados incluídos serão carregados automaticamente.
  4. Clique em Executar simulação (Run).
