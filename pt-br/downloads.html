Este conjunto de demonstração reúne cobertura da terra de 2025, um DEM de 30 m e uma máscara opcional da área de estudo para a Ilha do Maranhão. Os três rasters estão alinhados; a legenda e os limites usados para gerar a máscara também estão incluídos. Primeira execução

Abra o arquivo baixado.

Windows

Abra o arquivo .exe baixado em uma pasta onde você possa salvar os arquivos do projeto. Não é necessário instalar o Python.

Linux

Extraia o pacote para a pasta onde deseja manter o programa e abra BRMANGUE_Studio_Linux_x86_64. Se necessário, nas propriedades do arquivo, ative a permissão de execução.

No programa, selecione Ajuda → Criar atalhos no Linux. Depois, abra o BR-MANGUE Studio pelo menu de aplicativos ou pelo atalho com o logotipo na pasta. A área de trabalho também recebe um atalho quando estiver configurada.

Se mover a pasta do programa, crie os atalhos novamente. O pacote também inclui instruções e o arquivo Install_shortcuts.sh.

Seus dados ficam com você. O download inclui o ambiente de execução do programa, mas não inclui seus dados de cobertura da terra, DEM ou outros dados do estudo. Escolha uma pasta com espaço suficiente para os rasters anuais de saída.
