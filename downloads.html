First launch

Open the downloaded file.

Windows

Open the downloaded .exe from a folder where you can save project files. The app starts without a separate Python installation.

Linux

In the file manager, open the file's Properties and enable Allow executing file as a program, then double-click. If that option is unavailable, open a terminal in the Downloads folder and run:

chmod +x ./BRMANGUE_Studio_Linux_x86_64
./BRMANGUE_Studio_Linux_x86_64

Your data stays with you. Downloads include the application runtime, not MapBiomas, ANADEM, or study data. Choose a folder with enough disk space for annual raster outputs.
