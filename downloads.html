Optional sample dataset

Try the model with prepared data.

This sample dataset includes 2025 land cover, a 30 m DEM, and an optional study-area mask for Maranhão Island, Brazil. The three rasters are aligned; the class legend and the boundaries used to create the mask are included. The mask is the administrative union of the island’s four municipalities and retains internal water and small islands. The model accepts data and study areas from other regions.

Linux compatibility

Ubuntu tested; other systems may work.

The executable was built on Ubuntu 22.04 LTS and completed a 75-step raster pilot on Ubuntu 26.04.1 LTS. Other distributions remain unverified. It requires a graphical session (X11 or Wayland), an x86_64 processor, compatible glibc libraries, and xdg-open to open result files and folders.

First launch

Open the downloaded file.

Windows

Open the downloaded .exe from a folder where you can save project files. No separate Python installation is needed.

Linux

Extract the package to the folder where you want to keep the application, then open BRMANGUE_Studio_Linux_x86_64. If necessary, allow execution in the file Properties.

In the app, select Help → Create Linux shortcuts. Then open BR-MANGUE Studio from your applications menu or the logo shortcut beside the executable. A desktop shortcut is also created when your desktop directory is configured.

If you move the application folder, create the shortcuts again. The package also includes instructions and Install_shortcuts.sh.

Your data stays with you. The downloads include the application runtime, not your land-cover, DEM, or other study data. Choose a folder with enough disk space for annual raster outputs.
