Ready-to-run example · Maranhão Island

Try the model with real data

Download this project to test BR-MANGUE Studio with the Maranhão Island example. The ZIP contains the project and all required input files.

Download the test project (4.9 MiB ZIP)
  1. Extract the ZIP and keep its files and folders together.
  2. Open BR-MANGUE Studio and choose Project → Open project.
  3. Select brmangue_project.json. The included data load automatically.
  4. Click Run.

SHA-256: db59d4ee137f6fe4d8c8142ca049931b08cfa9dc0ab8a86707176753dd2a7046 · Checksum file

About this example: its CMMA sea-level curve is applied to Maranhão Island as test forcing, not as an island-specific projection. See the included source and license notes before reusing the data.

The application is available in English and Brazilian Portuguese. The application download does not include input rasters; the test project above includes its own data. Linux distributions other than Ubuntu 22.04 LTS have not been verified.
