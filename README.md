# BR-MANGUE Studio project site

This repository contains the public landing page for BR-MANGUE Studio. It is
published with GitHub Pages and provides the project overview, documentation
links, release downloads, research context, and GEOTAM information.

The source code is maintained separately in the private development repository:
`oceanpep/br-mangue-studio`.

## Local preview

Open `index.html` in a browser, or serve this folder with any static web
server. The page has no build step or runtime dependency.

## Publishing

The `main` branch is configured as the GitHub Pages source. Update the HTML and
CSS, commit the change, and GitHub Pages will publish the new version.
