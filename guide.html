Documentation

Prepare the data. Run a scenario. Review the results.

A short guide to the main BR-MANGUE Studio workflow, from aligned rasters to annual outputs.

The workflow

Four steps from project to results.

01

Create a project

Choose a project folder and a destination with enough space for the outputs.

02

Load the data

Select a categorical land-cover raster and an elevation raster with matching grid, extent, and coordinate reference system.

03

Set the scenario

Map source classes to model states, select the years and sea-level forcing, and choose processing options.

04

Run and review

Inspect annual maps, trajectories, transitions, and run metadata in the output folder.

Input data

What the model reads.

Required rasters are GeoTIFFs on a compatible grid. Prepare matching resolution, extent, and coordinate reference system before loading.

Land cover · requiredCategorical raster. Assign each source code to a model class or explicitly exclude it.
Elevation · requiredDigital elevation model used by the model rules. Record its vertical datum and data source.
Study-area mask · optionalRestricts processing to the selected cells.
Suitability layer · optionalUse only when the scenario is configured to apply this input.

Scenario settings

Choose how the run advances.

The Simulation panel sets the years, coastal forcing, and processing method. Save these choices with the source data and citations for the study.

ClassesUse the standard mapping or define named custom classes and behavior profiles. Custom mode starts blank.
Sea-level forcingEnter a constant annual rate or import cumulative levels from a CSV trajectory.
Continuous engineKeeps model state in memory. Consider available RAM when working with a large grid.
Persistent-block engineProcesses the grid in chunks and stores state on disk, with additional disk use and processing time.

Outputs

Files to inspect and keep.

Output options depend on the selected run settings. Preserve the project, input sources, and metadata alongside results.

Annual state mapsGeoTIFF maps for simulated years when annual export is enabled.
Trajectory and transition tablesCSV summaries of class totals and changes through time.
Run recordConfiguration, processing time, and resource information available for that execution.
