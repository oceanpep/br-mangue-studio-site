Input data

Start with aligned GeoTIFFs.

Land cover contains numeric categories; elevation supplies terrain height for the model rules. The raster cells must line up. The application can help reproject or align inputs when the source grids differ.

Processing engines

Choose how to process the grid.

Continuous

For speed when memory allows

Keeps model state in memory and was faster in the recorded benchmark runs. Check available RAM before choosing it for a very large raster.

Persistent blocks

For capacity and recovery

Stores model state in persistent files and processes it in chunks. It can make very large runs easier to recover, with additional disk use and processing time.

Both engines matched every annual state in the controlled Linux Ilha pilot. The archived long-horizon Windows runs used different class mappings, so their times cannot establish which engine is faster.

Results

Keep the evidence with the maps.

A run folder can contain the annual state rasters and tables that describe what the model changed and how long each step took.
