What it does

From raster data to annual results.

BR-MANGUE Studio brings the input data, model settings, and outputs together in one desktop workflow.

01

Prepare the grid

Load a categorical land-cover GeoTIFF and an aligned elevation GeoTIFF. A suitability layer and study-area mask are optional.

02

Set a scenario

Map raster classes to model roles, choose the time span and coastal parameters, and select continuous or block processing.

03

Inspect every step

Review annual maps, trajectories, transitions, figures, and run metadata. Exported files stay on your computer.

Get started

Download and open.

The desktop builds include Python and the project's required Python libraries. You do not need to install Python or packages separately. Your land-cover and elevation data are not included.
