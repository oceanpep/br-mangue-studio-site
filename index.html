Explore how mangrove landscapes may change.

BR-MANGUE Studio is a desktop application for running spatial cellular-automaton scenarios with land-cover and elevation data you provide.

What you can do

Build a scenario from your own spatial data.

The application brings data setup, model settings, processing, and results into one desktop workspace.

01

Prepare the inputs

Load a categorical land-cover raster and a digital elevation model on the same grid. A study-area mask and suitability layer are optional.

02

Set the model scenario

Map source classes to model states, choose the simulation years, and configure sea-level forcing and other model parameters.

03

Review the outputs

Inspect annual maps, trajectories, class transitions, and run metadata saved with the project.

A simple workflow

From aligned rasters to annual results.

01

Add the data

Select land-cover and elevation GeoTIFFs with matching extent, resolution, and coordinate system.

02

Map the classes

Assign each source category to a model state or exclude it from the scenario.

03

Choose the forcing

Set years and use a constant rate or a calendar-based sea-level trajectory.

04

Run and inspect

Compare yearly maps and tables, then keep the run metadata with the outputs.

Research workflow

Keep the data and results together.

Each run works with user-provided inputs and writes its outputs to the selected project folder. Input rasters remain unchanged.
