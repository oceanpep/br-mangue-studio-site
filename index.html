Desktop software for research

Explore how mangrove landscapes may change.

BR-MANGUE Studio simulates mangrove transitions over time using cellular automata and geospatial raster data. Build a scenario, run it on your computer, and inspect the results.

What it does

From raster inputs to annual maps.

Prepare two core inputs, define how their classes relate to the model, and run a simulation for the years you choose.

01

Use your own data

Load land-cover categories and a digital elevation model (DEM). Optional masks and suitability layers can refine a scenario.

02

Choose a workflow

Run the full grid in memory or process it in persistent blocks, depending on available memory and storage.

03

Inspect every run

Review maps, transition summaries, trajectories, and run metadata saved with your project.

Designed for flexible research

Bring data that fits your study.

BR-MANGUE Studio does not bundle a particular land-cover or elevation dataset. Use suitable geospatial inputs for your study area, coordinate system, resolution, and research question.
